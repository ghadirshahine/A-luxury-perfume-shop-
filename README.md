# دار الأُمراء — DAR AL-UMARA

متجر إلكتروني فاخر للعطور، مصمَّم من الصفر للجمهور العربي: **عربي أولًا مع دعم RTL كامل**، هوية بصرية ملكية (أسود مطفي، ذهبي شمبانيا، عاجي)، وتجربة تسوّق وظيفية كاملة — ليس واجهة ثابتة.

> المتجر مبني بـ HTML + CSS + JavaScript خالص. يتطلب تشغيل Sanity Studio المحلي بناءه مرة واحدة، ثم يقدّمه الخادم على `/studio`.

---

## التشغيل السريع

```powershell
# الطريقة الأولى: افتح الملف مباشرة
start index.html

# ابنِ Sanity Studio (من مجلده) لتحديث نسخة /studio المحلية
Set-Location "dar-al-aumara\studio"
npm run build

# شغّل المتجر وStudio على نفس النطاق
Set-Location ..\..
node scripts\serve-local.js
# المتجر: http://localhost:8080
# Sanity Studio: http://localhost:8080/studio
```

> البيانات كلها محلية (localStorage)، لذلك كل تفاعل — بحث، تصفية، سلة، طلب، تقييم، لوحة تحكم — يعمل فعليًا دون خادم.

### نمط الصفحة الواحدة

كل صفحة = `<main>` هيكلي + **5 سكربتات بالترتيب**:

```html
<script src="js/data.js"></script>   <!-- 1) البيانات والقواميس -->
<script src="js/store.js"></script>  <!-- 2) الحالة والأحداث (Store) -->
<script src="js/art.js"></script>    <!-- 3) محرّك الرسم SVG (Art) -->
<script src="js/ui.js"></script>     <!-- 4) الهيكل المشترك (UI) -->
<script src="js/pagename.js"></script><!-- 5) منطق الصفحة -->
```

الهيدر والفوتر والشريط السفلي والسلة الجانبية تُحقن تلقائيًا عبر `ui.js` اعتمادًا على `document.body.dataset.page`. لوحة التحكم تتعطّل فيها واجهة المتجر عبر `data-chrome="off"`.

### جلب المنتجات المنشورة من Sanity

المتجر يقرأ المنتجات المنشورة مباشرةً من Sanity project `xvmhw7dr` وdataset `production` عبر واجهة القراءة العامة (من دون وضع رمز وصول في المتصفح). تُحوّل الحقول والعلاقات والصور إلى شكل الكتالوج الذي تستخدمه صفحات المتجر. تتحدّث الصفحة بعد اكتمال الجلب، بينما تبقى بيانات السلة والحساب والتفضيلات محلية.

1. انشر المنتج في Sanity Studio؛ المسودات لا تظهر في المتجر.
2. أضف عنوان الموقع إلى **Sanity project → API → CORS origins**. للتطوير أضف `http://localhost:8080` ثم شغّل `python -m http.server 8080` من مجلد المشروع. أضف عنوان الموقع المنشور نفسه عند النشر.
3. افتح المتجر عبر خادم HTTP. فتح `index.html` مباشرةً عبر `file://` لا يتيح جلب Sanity بسبب قيود المتصفح.

عند تعذّر الاتصال يظهر تنبيه في المتجر ويُستخدم الكتالوج التجريبي مؤقتًا؛ راجع اتصال الشبكة وإعداد CORS. لا تضع رمز Sanity للكتابة في ملفات الواجهة الأمامية. إذا سبق استخدام رمز كتابة محفوظ داخل ملفات المشروع، ألغِه وأنشئ رمزًا بديلًا، ثم مرّره للسكربتات عبر متغير بيئة فقط.

## الربط بمتجر حقيقي (خارطة الاستبدال)

الطبقات مفصولة ليكون الاستبدال تدريجيًا دون لمس الواجهات:

1. **المنتجات** → مربوطة بالفعل بقراءة المنتجات المنشورة في Sanity عبر `Store.ready()` و`Store.products()`؛ الطلبات والعملاء ما زالوا محليين ويحتاجون API آمنًا.
2. **الدفع** → في `checkout.js` عند `Store.placeOrder(...)` أضف تكامل بوابة الدفع (شام برس / محافظ إلكترونية محلية) وانتقل إلى `success.html` برقم الطلب الفعلي.
3. **الشحن** → رسوم/أزمنة التسليم تأتي من `Store.settings()`؛ اربط مورّد الشحن في نفس نقطة الطلب.
4. **المصادقة** → `Store.account/login/updateAccount` تُستبدل بجلسة حقيقية مع الحفاظ على واجهة الدوال.
5. **صور المنتجات** → حاليًا فن SVG مولَّد (`art.js`)؛ عند توفر تصوير احترافي أضف `p.photos[]` وبدّل مصدر المعرض في `product.js`.
6. **لوحة التحكم** → نفس دوال `Store.*` (saveProducts/saveCoupons/setOrderStatus/saveSettings)؛ اربطها بنقاط REST المقابلة وستبقى اللوحة تعمل كما هي.

## SEO والأداء

- وسوم Meta + Open Graph + `canonical` في كل صفحة، وبيانات منظمة JSON-LD: `Organization`، `Product` (سعر/توفر/تقييم)، `BreadcrumbList`.
- خطوط عربية (Tajawal + Amiri) مع `preconnect`، وصور بتحميل كسول، وSVG خفيف بدل صور المنتجات النقطية.
- إتاحة الوصول: أدوار ARIA، `aria-live` للتنبيهات، تنقّل بلوحة المفاتيح، وتباين ألوان AA على الأسود.
- RTL أصيل: خصائص CSS منطقية (`inset-inline`, `margin-inline`) وتطبيع بحث عربي (همزات/تاء مربوطة) في `Store.norm`.

## قواعد التطوير داخل المشروع

- **لا مكتبات خارجية** ولا خطوة بناء؛ أي إضافة تُكتب يدويًا (الرسوم SVG في `admin.js` مثالًا).
- **كل نص عربي**، والأرقام بالتنسيق `1,234.500 د.ك` عبر `Store.price`، والتواريخ `dd/mm/yyyy`.
- **تهريب إلزامي** لأي قيمة قادمة من المستخدم أو التخزين قبل `innerHTML` عبر `Store.esc`.
- الأيقونات من سبرايت `Art.iconSprite()` بصيغة `<svg class="ic"><use href="#i-name"/></svg>` — لا إيموجي.
- تغييرات الحالة تتم عبر دوال `Store.*` حصرًا، والقوائم تسمع الأحداث (`Store.on('cart' …)`) بدل إعادة الجلب.
- الأنماط تتبع رموز `style.css` (`--gold-500`, `--s-4`, `--r-md`, `--dur` …) ولا ألوان مباشرة خارجها إلا للضرورة.

## للتحقق السريع

```powershell
node --check js/admin.js   # وأي ملف JS آخر
```

صفحة القبول المقترحة قبل التسليم: الرئيسية → المتجر (فلترة + بحث + عرض سريع) → إضافة للسلة → كوبون + تغليف → الدفع → تتبع الطلب من الحساب → تقييم العطر → لوحة التحكم (تعديل منتج، تغيير حالة طلب، إضافة كوبون).
